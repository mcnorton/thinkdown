## 왜 Thinkdown인가

생각을 정리할 땐 트리가 편한데, 남에게 넘길 결과물은 마크다운입니다. 그래서 늘 두 번 일합니다 —
마인드맵 도구에서 구조를 잡고, 에디터를 열어 다시 옮겨 적습니다. 옮기는 동안 계층이 흐트러지고,
나중에 구조를 고칠 땐 맵과 문서 중 어느 쪽이 최신인지 알 수 없게 됩니다.

Thinkdown은 **옮겨 적는 단계를 없앱니다.** 맵이 곧 문서입니다.
노드를 하나 만들면 마크다운 한 블록이 생기고, 가지를 옮기면 목차가 따라 움직입니다.
오른쪽 패널의 마크다운은 언제나 최신이라, 필요할 때 **[복사]** 한 번이면 끝입니다.

## 이런 걸 만들 때 씁니다

|  |  |
|---|---|
| **AI 프롬프트 · 스킬 · 에이전트 정의** | 역할 · 입력 · 규칙 · 출력 형식을 가지로 나눠 짜고, 깨끗한 마크다운으로 붙여넣습니다. 규칙 한 덩어리를 다른 위치로 옮기는 것도 드래그 한 번입니다. |
| **기획서 · 제안서 뼈대** | 큰 덩어리부터 잡고 안을 채웁니다. 순서가 마음에 안 들면 챕터를 통째로 위아래로 옮깁니다. |
| **회의록 · 강의 노트** | 말이 튀는 대로 가지에 붙여 두고, 끝나면 트리만 정리해 그대로 공유합니다. |
| **README · 기술 문서 목차** | 표 · 코드블록 · 링크 · 이미지를 노드로 넣고, 문서 전체 또는 특정 챕터만 내보냅니다. |

## 맵이 곧 마크다운입니다

위 화면의 맵은 오른쪽에 이 마크다운을 그대로 만들어 둡니다. 따로 변환하는 단계가 없습니다.

```markdown
# 역할

당신은 시니어 코드리뷰어입니다. 변경된 코드만 읽고, 실제로 깨지는 문제를 먼저 보고합니다.

# 입력

- 변경 diff와 대상 브랜치
- 테스트 실행 결과
- 리뷰 강도 (low / medium / high)

# 출력 형식

| 항목 | 내용 |
| --- | --- |
| 심각도 | high / medium / low |
| 위치 | 파일:줄 |
```

**제목 노드를 클릭하면 그 챕터만** 미리보기·복사·내보내기 됩니다. 긴 문서에서 필요한 한 조각만
가져다 쓸 때 편합니다. 이때 **[복사]는 제목 단계를 `#`부터 다시 맞춰** 줍니다 — 문서 한가운데
있던 `### 과일`이 붙여넣는 곳에서는 `# 과일`이 됩니다. 보이는 그대로가 필요하면 [복사] 옆
꺾쇠에서 고르면 됩니다.

## 무엇이 좋은가

| | |
|---|---|
| ⌨️ **손이 멈추지 않습니다** | `Tab`으로 자식, `Enter`로 형제. 마우스를 잡지 않고 트리를 끝까지 펼칩니다. |
| 🧩 **본문 9종** | 문단 · 불릿 · 개요 · 인용 · 코드 · 표 · 이미지 · 링크 · 구분선. 표는 격자에서 셀을 직접 편집하고, 이미지·링크는 썸네일과 제목이 붙은 카드로 보입니다. |
| 🌿 **드래그로 구조 변경** | 노드 위에 놓으면 그 아래로 이동(제목 깊이 자동 조정), 사이에 놓으면 순서 변경. 좌표를 옮기는 게 아니라 목차를 고치는 겁니다. |
| ♻️ **무손실 왕복** | 문서는 마크다운 그대로 저장됩니다. 내보냈다 다시 가져와도 트리가 그대로 복원됩니다. |
| 📁 **폴더와 검색** | 문서를 폴더로 묶고 드래그로 옮깁니다. 폴더를 골라 두면 새 문서가 그 안에 생깁니다. 검색은 현재 문서와 전체 문서를 함께 찾아 그 노드로 데려갑니다. |
| ↩️ **되돌리기 / 다시실행** | `⌘Z` · `⇧⌘Z`. 연속으로 친 글자는 한 단계로 묶입니다. |
| 🌗 **라이트 · 다크** | 시스템 설정을 따라가거나 직접 고릅니다. 브랜치별 컬러테마도 켤 수 있습니다. |
| 🔎 **읽기 편한 화면** | 텍스트를 키우고, 긴 글을 쓸 땐 편집영역을 넓힙니다. 글꼴도 시스템 기본 대신 직접 고를 수 있습니다. |
| 💾 **파일로 오갑니다** | `.md` 가져오기 / 내보내기, 전체 문서를 `.zip`으로 백업하고 복구합니다. |
| 🔄 **알아서 최신** | 새 버전이 나오면 조용히 받아 두고 재시작할 때 적용됩니다. macOS · Windows · Linux 모두 됩니다. |

## 내려받기

**[⬇︎ 최신 릴리스에서 내 운영체제용 파일 받기](https://github.com/mcnorton/thinkdown/releases/latest)**

| 운영체제 | 받을 파일 | 설치 |
|---|---|---|
| **macOS** — Apple Silicon(M1 이상) | `Thinkdown-<버전>-arm64.dmg` | 열어서 **Thinkdown**을 응용 프로그램 폴더로 드래그 |
| **macOS** — Intel | `Thinkdown-<버전>-x64.dmg` | 위와 같습니다 |
| **Windows** 10 · 11 (64비트) | `Thinkdown-Setup-<버전>.exe` | 실행하면 설치됩니다(관리자 권한 필요 없음) |
| **Linux** (64비트) | `Thinkdown-<버전>.AppImage` 또는 `.deb` | AppImage는 `chmod +x` 후 실행, deb는 `sudo dpkg -i` |

- 내 Mac의 칩은 **Apple 메뉴 → 이 Mac에 관하여**에서 볼 수 있습니다. "Apple M…"이면 arm64,
  "Intel"이면 x64입니다.
- macOS 빌드는 Apple Developer ID로 서명·공증되어 있어 경고 없이 바로 열립니다.
- Windows 빌드는 **코드 서명되어 있습니다** — 설치 화면에 게시자 이름(**McNorton&Education**)이
  표시됩니다. 다만 서명을 시작한 지 얼마 되지 않아 평판이 쌓이기 전까지는 **SmartScreen 경고**가
  뜰 수 있습니다. 이때는 **추가 정보 → 실행**을 누르면 설치됩니다.
  - **"실행" 선택지가 아예 없다면** 그 PC는 **스마트 앱 컨트롤(Smart App Control)** 이 켜져 있는
    상태입니다. 서명된 앱이라도 평판이 없으면 막힐 수 있고, 앱별 예외를 둘 수 없습니다.
    **설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤**에서 상태를 볼 수 있고,
    Windows 11을 **새로 설치한** PC에서만 기본으로 켜집니다(업그레이드한 PC나 Windows 10은 해당 없음).
  - 같은 화면의 **평판 기반 보호 설정**에서 "앱 및 파일 검사"가 **차단**으로 되어 있어도 실행이
    막힙니다. 이 경우 **경고**로 바꾸면 넘어갈 수 있습니다.
- 계정을 만들 필요도, 로그인할 필요도 없습니다. 현재 모든 기능을 무료로 쓸 수 있습니다.

## 처음 60초

1. 가운데 **문서 제목**을 클릭해 이름을 적습니다.
2. `Tab` — 자식 제목이 생깁니다. `Enter` — 같은 층에 형제가 생깁니다.
3. 제목에서 `Shift+Enter` — 그 제목에 딸린 본문 노드가 생깁니다. `Alt+1~9`로 종류를 바꿉니다.
4. 왼쪽 맵에서 **제목을 클릭**하면 오른쪽 마크다운이 그 챕터로 좁혀집니다.
5. 오른쪽 위 **[복사]** — 붙여넣을 준비 완료.

# 사용법

처음 쓸 때 알아 두면 좋은 것들입니다. 순서대로 읽지 않아도 되고, 필요할 때 찾아보면 됩니다.

## 노드에는 세 가지 상태가 있습니다

한 번 클릭하면 **선택**, 더블클릭하면 **편집**입니다. 그리고 아무것도 건드리지 않은 상태가 읽기
전용입니다. 같은 `Enter`라도 선택 중일 땐 새 노드를 만들고, 편집 중일 땐 입력을 마칩니다.
편집을 마치려면 `Enter` 또는 `Esc`를 누르면 됩니다.

**선택은 `Esc`로만 풀립니다.** 입력을 마쳐도, 캔버스 빈 곳을 눌러도 방금 쓰던 노드는 선택된 채로
남습니다 — 다른 노드를 고르면 그쪽으로 옮겨갈 뿐입니다. 그래서 키보드로 이어서 작업할 때
"지금 어디에 있는지"를 잃어버리지 않습니다.

**선택한 노드는 화면 밖으로 나가지 않습니다.** 새 노드를 만들거나 링크 썸네일이 늦게 도착해
맵이 밀려나면, 그 노드가 **화면 가운데로** 돌아옵니다. 반대로 직접 스크롤해서 옆으로 치워 둔
노드는 그대로 둡니다 — 화면을 되돌려 놓지 않습니다.

**화면이 작아지는 건 챕터를 옮길 때뿐입니다.** 고른 노드와 그 제목이 한 화면에 안 들어가면
맵을 조금 줄여 보여 주는데, 이건 *다른 챕터로 건너갈 때* 한 번만 합니다. 같은 챕터 안에서
형제를 하나씩 짚어 갈 땐 배율이 그대로입니다 — 이미 보고 있는 맥락을 다시 보여 주려고 화면이
커졌다 작아지면 그게 더 어지럽기 때문입니다. **더블클릭해서 편집에 들어가면 곧바로 100%로
돌아옵니다.** 직접 맞춘 배율은 앱이 건드리지 않습니다.

## 트리 넓히기

| 키 | 하는 일 |
|---|---|
| `Tab` | 지금 노드의 **자식 제목**을 만듭니다. 문서 제목에서 누르면 첫 챕터가 생깁니다. |
| `Enter` (선택 상태) | 같은 층에 **형제 노드**를 만듭니다. 제목이면 제목이, 본문이면 같은 종류의 본문이 생깁니다. |
| `Shift+Enter` (제목에서) | 그 제목에 딸린 **본문 노드**를 붙입니다. 깊이에 상관없이 언제든 됩니다. |
| `Esc` | 편집을 마치고 선택 상태로 돌아갑니다. |

> 내용이 비어 있는 새 노드에서는 형제가 만들어지지 않습니다(노드가 살짝 흔들립니다).
> 빈 노드만 잔뜩 생기는 일을 막기 위한 장치입니다.

## 본문 종류 바꾸기 — `Alt+1` ~ `Alt+9`

본문 노드에 포커스가 있을 때 누릅니다.

| 키 | 종류 | 마크다운 |
|---|---|---|
| `Alt+1` | 문단 | 그냥 단락 |
| `Alt+2` | 불릿 | `* 항목` |
| `Alt+3` | 개요 | `1. 항목` |
| `Alt+4` | 인용 | `> 인용` |
| `Alt+5` | 코드 | 펜스로 감싼 코드 블록 |
| `Alt+6` | 표 | GFM 표 (격자에서 편집) |
| `Alt+7` | 이미지 | `![alt](url)` |
| `Alt+8` | 링크 | `[텍스트](url)` |
| `Alt+9` | 구분선 | `---` 가로선 (내용 없음, 연결선도 붙지 않습니다) |

노드 왼쪽 위의 **종류 태그를 클릭**하거나 **우클릭 → 종류 변경**으로도 고를 수 있습니다.
다만 내용이 들어 있는 노드는 글(문단·불릿·개요·인용·코드)끼리만 바꿀 수 있습니다 —
표·이미지·링크로 바꾸면 내용이 사라지기 때문에, 그 전환은 `Alt` 단축키로만 열어 뒀습니다.

**타이핑만으로 바뀌기도 합니다.** 문단에서 `1. `을 치면 개요로, `* ` 또는 `- `를 치면 불릿으로,
`https://…` 뒤에 공백을 치면 링크로 바뀝니다.

## 목록 안에서 (불릿 · 개요 · 인용)

목록은 노드 하나에 여러 줄로 씁니다. 마커와 번호는 알아서 붙습니다.

- `Enter` — 같은 깊이로 다음 항목이 생깁니다.
- `Tab` / `Shift+Tab` — 항목을 한 단계 들여쓰거나 내어씁니다(번호도 다시 매겨집니다).
- 항목 맨 앞에서 `Backspace` — **앞 항목과 합쳐집니다.** 실수로 `Enter`를 눌러 생긴 항목을
  되돌릴 때 씁니다. 항목이 하나뿐이고 비어 있으면 마커가 사라지고 그냥 문단이 됩니다.
- 불릿에서 `⌘Enter` — 그 줄에 **체크박스**를 붙입니다(없음 → `- [ ]` → `- [x]` → 없음).
  오른쪽 미리보기의 체크박스는 **직접 눌러서** 켜고 끌 수 있고, 맵의 글자가 함께 바뀝니다.

## 표 · 이미지 · 링크

- **표**는 더블클릭해서 편집합니다. `Tab`으로 옆 칸, `Enter`로 아랫줄(마지막 줄이면 행이 하나
  늘어납니다). 편집 중에만 보이는 거터의 **＋** 로 행·열을 더하고 **🗑** 로 지웁니다.
- **이미지 · 링크**는 **보이는 줄이 곧 입력란**입니다. 평소엔 읽기 전용이라 글자처럼 보이다가,
  **고치고 싶은 줄을 더블클릭**하면 그 자리에서 편집됩니다. `Tab`으로 다음 칸, `Enter`로 마칩니다.
  - **새 링크에는 주소만 넣으면 됩니다.** 표시 텍스트 줄은 값이 정해지기 전까지 아예 보이지
    않습니다 — 주소를 넣은 뒤 이름을 따로 지어 줄 필요가 없습니다.
    `example.com`처럼 `https://`를 빼고 써도 확정할 때 알아서 붙습니다.
  - 주소를 확정하면 `가져오는 중…`이 잠깐 뜨고, 그 페이지의 **제목과 대표 이미지가 한 번에**
    채워집니다. 제목을 못 가져오면 `example.com` 같은 도메인이 들어갑니다.
  - **채워진 뒤에** 표시 텍스트 줄이 나타납니다. 마음에 안 들면 더블클릭해서 고치면 됩니다. 직접 쓴 표시 텍스트는 주소를 바꿔도
    그대로 남습니다. 주소 줄 오른쪽의 **↗** 를 누르면 확인 후 브라우저로 열립니다.
  - 가져오려면 해당 사이트에 접속해야 하므로, 원치 않으면 **설정 → 일반 → 링크노드 썸네일 표시**에서
    끌 수 있습니다.
  - **이미지도 쓰는 방법은 완전히 같습니다.** 위에 적은 링크 이야기가 그대로 적용됩니다 —
    주소만 넣으면 되고, 표시 텍스트는 자동으로 채워진 뒤에 나타나며, 더블클릭해서 고칩니다.
    **유튜브 주소**를 넣으면 영상 포스터와 **▶** 가 뜨고 표시 텍스트가 영상 제목이 됩니다.
    ▶ 또는 ↗ 를 누르면 **창이 열려** 거기서 재생됩니다 — 맵 위에서 영상이 돌아가지 않습니다.
  - 다만 그림은 **잘리지 않습니다.** 링크 썸네일은 카드 모양에 맞춰 자르지만 이미지 노드에서는
    그림이 곧 내용이라 비율을 그대로 지킵니다. 같은 이유로 **불러오지 못하면 알려 줍니다**
    (링크 썸네일은 조용히 숨깁니다).

## 구조 바꾸기 (마우스)

| 동작 | 결과 |
|---|---|
| 노드를 다른 노드 **위에** 끌어다 놓기 | 그 노드의 **아래로 이동**합니다. 제목이면 깊이(`#`→`##`)가 알아서 맞춰집니다. |
| 노드를 **노드 사이에** 놓기 | 형제 **순서**만 바뀝니다(계층은 그대로). |
| 선택한 제목 위·아래의 **↑ ↓** | 같은 부모 안에서 앞뒤 제목과 자리를 바꿉니다(사이에 있는 문단 형제는 건너뜁니다). 딸린 하위 노드는 함께 움직입니다. |
| **우클릭 → 삭제** | 노드를 지웁니다. 하위 노드가 있으면 몇 개가 함께 지워지는지 먼저 물어봅니다. |

> **내용을 다 지워도 노드는 사라지지 않습니다.** 지우는 방법은 우클릭 [삭제] 하나뿐이라,
> `Backspace`를 몇 번 더 눌렀다고 가지가 통째로 날아갈 일이 없습니다.

## 제목에 관한 세 가지 규칙

- **문단에서 친 `#`는 그냥 글자입니다.** 해시태그처럼 남고 제목으로 승격되지 않습니다
  (문단 하나 때문에 계층이 튀는 걸 막습니다).
- **제목 앞의 `#` 마크는 표시 전용입니다.** 글자 크기와 색이 제목과 구분되어 있고, 편집 대상이
  아니라서 실수로 지워지지 않습니다. 단계(`#`의 개수)는 `Tab`으로 하위 제목을 만들거나 가지를
  드래그해 옮길 때만 바뀝니다 — 오타 하나로 트리가 평평해지는 사고가 없습니다.
- **비어 있는 제목은** `Backspace` 한 번으로 문단이 됩니다(하위 노드가 없을 때).

## 문서와 화면

| 키 | 하는 일 |
|---|---|
| `⌘N` | 새 문서 (왼쪽에서 폴더를 골라 뒀으면 그 안에 만듭니다. 비어 있는 문서가 있으면 그걸 재사용합니다) |
| `⌘B` | 왼쪽 탐색기 접기 / 펴기 |
| `⌘⌥B` | 오른쪽 마크다운 패널 접기 / 펴기 |
| `⌘,` | 설정 (테마 · 글꼴 · 텍스트 크기 · 편집영역 너비 · 연결선 · 백업 · 업데이트) |
| `⌘Z` / `⇧⌘Z` | 되돌리기 / 다시실행 |
| `Ctrl + 휠` · 트랙패드 핀치 | 맵 확대 / 축소 (빈 공간을 끌면 이동) |

> Windows · Linux에서는 `⌘` 대신 `Ctrl`을 씁니다.

> 노드 안에서 글자를 고치는 중이라면 `⌘Z`는 **그 입력칸의 글자 단위 되돌리기**로 동작합니다.
> 맵 전체를 되돌리려면 입력을 마치고(`Esc`) 누르세요.

## 보기 설정 (`⌘,`)

**[외형]** 에서 맵이 보이는 방식을 고칩니다. 바꾸는 즉시 반영되고, 다음에 열 때도 그대로입니다.

| 항목 | 하는 일 |
|---|---|
| **더 큰 텍스트** | 맵과 미리보기의 글자를 함께 키웁니다(표 안의 글자도). 보통 · 시원하게 · 광활하게. |
| **연결선** | 노드를 잇는 선의 모양 — 곡선 · 직선 · 꺾인선 · 둥근 꺾인선. |
| **글꼴 선택** | 기본은 시스템 글꼴입니다. [사용자 지정]을 고르면 본문용·고정폭용 글꼴을 따로 지정할 수 있고, 입력칸에 글자를 치면 설치된 글꼴이 그 글꼴 모양 그대로 후보에 뜹니다. |
| **본문 편집영역 너비** | 긴 글을 쓸 때 글 쓰는 노드의 가로폭을 넓힙니다(보통 · 넓게 · 매우 넓게). 표·이미지·링크는 제 크기를 지킵니다. |

**[일반]** 에는 언어(시스템 · 한국어 · English — 바꾸면 창을 다시 불러옵니다), 화면 모드(라이트/다크/시스템), 링크노드 썸네일 표시, 전체 백업·복원, 업데이트
확인이 있습니다. 항목 이름 옆의 **(?)** 에 마우스를 올리면 짧은 설명이 뜹니다.

> 글꼴이 마음에 들지 않으면 [글꼴 선택] → [사용자 지정]에서 직접 지정할 수 있습니다.

## 내 데이터는 내 기기에

계정도, 서버도, 수집도 없습니다. 문서는 전부 이 컴퓨터 안에 저장되고 밖으로 나가지 않습니다.
앱이 네트워크를 쓰는 건 두 가지뿐입니다 — **새 버전이 있는지 확인할 때**, 그리고 **링크 노드의
썸네일을 가져올 때**(그 링크의 사이트에만, 설정에서 끌 수 있습니다).
언제든 `.zip` 백업이나 `.md` 내보내기로 통째로 꺼내 갈 수 있습니다.

## 개발

빌드 도구 없이 도는 **바닐라 JS ES 모듈** 싱글페이지 앱이고, Electron으로 데스크톱 앱이 됩니다.
번들러도, 프레임워크도, 가상 DOM도 없습니다 — 모든 변경은 `core/model.js`를 지나 한 개의 옵저버로
화면 전체를 다시 그립니다. 설계·모듈·데이터 모델 문서는 저장소의 `docs/`에 있습니다.

```bash
npm start      # Electron 데스크톱 앱 실행 (dev)
npm test       # 순수 로직 테스트 (node --test test/*.test.mjs)
npm run dist   # 데스크톱 앱 빌드 → dist/<version>/
```
