#자주 묻는 질문FAQ

마크다운 에디터인가요?Is this a Markdown editor?
네. 결과물은 표준 마크다운입니다. 다만 마크다운을 줄로 쓰는 대신 생각을 가지로 펼쳐 쓰면, 그것이 마크다운이 됩니다. 복사하거나 .md 파일로 내보낼 수 있습니다.Yes. What comes out is standard Markdown. Instead of writing Markdown line by line, you write your thinking out in branches, and that becomes the Markdown. You can copy it or export it as a .md file.
생각코드가 뭔가요?What is thoughtcode?
의사코드(pseudocode)에서 따온 말입니다. 의사코드는 코드를 짜기 전에 무엇을 어떤 순서로 할지 사람의 말로 적은 설계입니다. Thinkdown의 가지는 들여쓰기이고, 가지 끝의 문장은 의사코드 한 줄입니다. 생각은 당신이 쓰고, 그것을 코드나 글로 빌드하는 일은 AI가 합니다.The name comes from pseudocode: the plan you write in plain words, before any code, of what to do and in what order. In Thinkdown the branches are the indentation, and the sentence at the end of each branch is a line of pseudocode. You write the thinking; building it into code or prose is the AI's job.
다른 마인드맵 앱과 무엇이 다른가요?How is this different from other mind-map apps?
가지 끝에 단어가 아니라 문장이 들어갑니다. 전통적인 마인드맵은 연상을 촉발하는 키워드를 적기 때문에, 자세한 생각은 만든 사람의 머릿속에만 남습니다. Thinkdown은 가지 끝에 본문을 그대로 풀어쓸 수 있기 때문에, 생각의 흐름에 따라 정리된 가지들이 결국 하나의 문서가 됩니다. 작성된 문서는 맵 · 마크다운 · 미리보기 세 가지 모습으로 동시에 존재하고, 필요한 가지를 선택해서 내보내거나 복사할 수 있습니다.Branches hold sentences, not keywords. A traditional mind map records keywords meant to trigger recall, so the detailed thinking stays inside the author's own head. In Thinkdown a branch holds the body text itself, so branches arranged along your train of thought end up being the document. What you write exists as three views at once — map, Markdown and preview, and you can select any branch to copy or export just that part.
마크다운을 몰라도 쓸 수 있나요?Do I need to know Markdown?
쓸 수 있습니다. 마크다운은 결과물이지 입력 방식이 아닙니다. 가지에 문장을 적고 Tab 과 Enter 로 가지를 늘리면 됩니다. 기호를 칠 필요는 없지만 쳐도 알아서 바뀝니다 — - 는 불릿, 1. 은 개요, > 는 인용이 됩니다. 표는 격자에서 칸을 직접 채웁니다. 제목은 Tab 으로 만들거나 빈 문단에서 # 를 치면 되고, 이미 쓴 문장 속의 # 은 글자 그대로 남습니다 — 오타 하나로 문서의 구조가 흐트러지지 않습니다.You don't. Markdown is the output, not the input method. Write sentences on branches and grow them with Tab and Enter. You never have to type a marker, though they work if you do — - for a bullet, 1. for an outline, > for a quote. Tables are filled cell by cell. For a heading, press Tab or type # in an empty paragraph; a # inside a sentence you have already written stays plain text, so a stray keystroke can't scramble your outline.
Obsidian 같은 노트 앱과 함께 쓸 수 있나요?Does it work alongside Obsidian and other note apps?
잘 맞습니다. 노트 앱이 이미 쓴 글들을 서로 잇는 데 강하다면, Thinkdown은 빈 화면에서 글 하나의 뼈대를 처음 세우는 데 집중합니다. 맵으로 구조를 잡고 [복사] 하거나 .md 로 내보내 노트 앱에 넣으면 됩니다. 표준 마크다운이라 그대로 읽힙니다.They fit together well. Note apps shine at linking what you've already written; Thinkdown focuses on building the skeleton of one piece from a blank screen. Shape it as a map, then [Copy] it or export it as .md into your note app — it's standard Markdown, so it reads as-is.
AI가 맵을 대신 그려 주나요?Will the AI draw the map for me?
정반대입니다. 생각의 주도권을 인공지능에게 넘겨주지 마세요. 이 프로젝트의 핵심 가치입니다. 개념도를 완성된 채로 받았을 때의 학습 효과는 g=0.653이었고, 학생이 직접 그렸을 때는 g=0.933이었습니다(STEM 개념도 메타분석). 생각을 AI가 대신 그려 주면 직접 만들면서 얻게 되는 많은 것들이 사라집니다. AI의 역할은 이미 만들어진 구조에서 빠진 곳을 짚어 주는 정도가 가장 알맞다고 봅니다. 더 읽기 →Quite the opposite. Don't hand the thinking over to AI — that is what this project is about. Students handed a finished concept map showed a learning effect of g=0.653; students who drew it themselves, g=0.933 (STEM concept-mapping meta-analysis). Having AI draw your thinking for you removes much of what building it would have taught. We think AI fits best where it points at what is missing in a structure you have already made. Read more →
내 문서는 어디에 저장되나요?Where are my documents stored?
설치한 컴퓨터 안에만 저장됩니다. 계정도 서버도 없습니다. 앱이 네트워크를 쓰는 경우는 새 버전 확인과 붙여넣은 링크의 썸네일 가져오기 두 가지뿐이고, 썸네일은 설정에서 끌 수 있습니다. 연결이 없어도 열기 · 편집 · 저장 · 내보내기가 모두 그대로 동작합니다.Only on the computer you installed it on. There is no account and no server. The app uses the network for two things — checking for updates and fetching a thumbnail for a link you pasted — and thumbnails can be turned off in settings. Opening, editing, saving and exporting all work with no connection at all.
백업하거나 새 컴퓨터로 옮길 수 있나요?Can I back up or move to a new computer?
문서와 폴더 구조 전체를 .zip 파일 하나로 내보내 저장할 수 있습니다. 새 컴퓨터에서는 앱을 설치하고 그 파일을 그대로 불러들여 복구하면 됩니다. 문서를 하나씩 .md 로 내보낼 수도 있습니다. 또 새 버전으로 업데이트할 때마다 앱이 먼저 문서를 자동으로 백업해 두고 최근 3회분을 보관합니다.Export every document and your folder structure as a single .zip, then restore from that file. On a new machine, install the app and restore the .zip. Individual documents also export as .md. And every time the app updates, it first backs your documents up automatically and keeps the last three.
Windows에서 경고 화면이 뜹니다.Windows shows me a warning.
설치 파일은 코드 서명되어 있어 설치 화면에 게시자 이름 McNorton&Education 이 표시됩니다. 다만 서명을 시작한 지 얼마 되지 않아 평판이 쌓이기 전까지는 SmartScreen 경고가 뜰 수 있습니다. 이때는 추가 정보 → 실행을 누르면 설치됩니다. "실행" 선택지가 아예 없다면 그 PC는 스마트 앱 컨트롤이 켜져 있는 상태입니다 — Windows 11을 새로 설치한 PC에서만 기본으로 켜지며, 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤에서 확인할 수 있습니다. macOS 빌드는 Apple Developer ID로 서명·공증되어 있어 경고 없이 열립니다.The Windows installer is code-signed, so the install screen shows the publisher name McNorton&Education. Signing is new, though, so SmartScreen may still warn until the certificate builds reputation — choose More info → Run anyway and it installs. If there is no "Run anyway" at all, that PC has Smart App Control turned on — it is only on by default on clean installs of Windows 11, and you can check it under Settings → Privacy & security → Windows Security → App & browser control. The macOS build is signed and notarised with an Apple Developer ID, so it opens without any warning.
