사용법How to use it

생각을 가지처럼 늘어놓으면, 그 지도가 그대로 마크다운 문서가 됩니다. 꼭 필요한 것만 모았습니다. 순서대로 읽지 않아도 됩니다. Lay out your thoughts as branches, and the map becomes a Markdown document as it is. Only the essentials are here. Read in any order.

앱 안에도 같은 내용이 있습니다. 탐색기의 Thinkdown Guide 폴더에 빠른 안내와 사용설명서를 넣어두었습니다. 설명서도 Thinkdown 문서라 읽으면서 바로 연습할 수 있습니다. Windows · Linux 에서는 ⌘ 를 Ctrl 로, ⌥ 를 Alt 로 읽으세요. The same guide lives inside the app too: the Thinkdown Guide folder in the Explorer holds a Quick Guide and a Manual. They are Thinkdown documents, so you can practise as you read. On Windows and Linux, read ⌘ as Ctrl and ⌥ as Alt.

빠르게 적기 — Enter · Tab · 화살표 Writing fast — Enter, Tab and the arrows

생각을 적는 데 필요한 키는 이것뿐입니다. 노드를 한 번 눌러 고른 뒤 눌러 보세요. These are the only keys you need to get your thoughts down. Click a node once to select it, then try them.

키Key 하는 일Does
Enter 같은 단계에 하나 더One more at the same level
Tab 한 단계 아래에 하나 더One more, one level down
Shift+Enter 제목 아래에 문단 붙이기A paragraph under a heading
← → ↑ ↓ 부모 · 자식 · 위 · 아래 노드로 옮겨 다니기Move to the parent, child, node above or below
더블클릭Double-click 그 노드의 글 고치기Edit that node's text
Esc 고치기를 마치기Finish editing

제목을 고른 채 Tab 으로 하위 제목을 만들고, 글을 쓰고 Esc, 다시 Enter 로 다음 제목. 손을 키보드에서 떼지 않고 생각을 쏟아 낼 수 있습니다. 순서나 단계가 틀려도 괜찮습니다. 나중에 끌어서 옮기면 됩니다. Select a heading, press Tab for a child heading, type, press Esc, then Enter for the next one. Your hands never leave the keyboard. Don't worry about order or levels — you can drag things into place later.

  • ⌘Z / ⇧⌘Z — 되돌리기 / 다시실행 ⌘Z / ⇧⌘Z — undo / redo
  • ⌘D — 고른 노드를 아래 노드까지 통째로 복제 ⌘D — duplicate the selected node with everything under it
  • ⌥1 ~ ⌥9 — 본문 종류 바꾸기 (문단 · 불릿 · 개요 · 인용 · 코드 · 표 · 이미지 · 링크 · 구분선) ⌥1 to ⌥9 — change the body type (paragraph, bullet, outline, quote, code, table, image, link, divider)
  • ⌘N — 새 문서 · F5 — 슬라이드쇼 ⌘N — new document · F5 — slideshow
  • 우클릭 → [삭제] — 노드 지우기 (글을 다 지워도 노드는 남습니다) Right-click → [Delete] — delete a node (clearing its text never removes it)

첫 글자로 바꾸기Changing type with the first character

종류를 고르지 않아도, 문단의 첫 글자로 바로 바뀝니다. No need to pick a type. The first character of a paragraph does it.

문단 맨 앞에At the start 바뀌는 것Becomes
* 또는or - + 띄어쓰기+ space 불릿 목록Bullet list
1. + 띄어쓰기+ space 번호 목록 (개요)Numbered list (outline)
> + 띄어쓰기+ space 인용Quote
# (빈 문단에서)(in an empty paragraph) 제목Heading
``` 코드Code
주소 + 띄어쓰기An address + space 링크 노드Link node
  • 문단 중간에 주소를 치고 띄어쓰기를 누르면 그 주소가 링크 알약이 됩니다. Type an address in the middle of a paragraph and press Space, and it becomes a link pill.
  • 줄에 --- 만 쓰면 편집을 마칠 때 그 자리가 구분선으로 나뉩니다. A line of just --- becomes a divider when you finish editing.
  • 불릿을 쓰다가 ⌘Enter 를 누르면 체크박스가 생깁니다. 다시 누르면 체크됩니다. ⌘Enter in a bullet list adds a checkbox. Press it again to tick it.
  • 목록 안에서: Enter 다음 항목 · Tab / Shift+Tab 들여쓰기 / 내어쓰기 · 빈 항목에서 Enter 목록 끝내기 Inside a list: Enter next item · Tab / Shift+Tab indent / outdent · Enter on an empty item ends the list

꼭 알아 둘 마크다운Markdown you should know

지도의 제목은 마크다운의 제목이 되고, 본문 노드는 그 아래의 문단 · 목록 · 표가 됩니다. 오른쪽 마크다운 패널(⌘⌥B)을 열어 두면 둘이 함께 바뀌는 것을 볼 수 있습니다. Headings on the map become Markdown headings, and body nodes become the paragraphs, lists and tables under them. Open the Markdown panel on the right (⌘⌥B) to watch both change together.

**굵게bold**굵은 글씨Bold text문단 안에 그대로Inside a paragraph
*기울임italic*기울인 글씨Italic text문단 안에 그대로Inside a paragraph

코드 블록은 ``` 로 위아래를 감싸고, 표는 칸을 | 로 나눕니다. 지도에서는 코드 노드 · 표 노드가 됩니다. A code block is wrapped in ``` above and below, and a table separates cells with |. On the map they become a code node and a table node.

링크와 그림Links and images

링크 노드에는 주소만 넣으면 됩니다. 페이지 제목과 대표 그림이 저절로 채워지고, 이름은 더블클릭해서 고칠 수 있습니다. A link node only needs an address. The page title and preview image fill in by themselves; double-click the name to change it.

문단 안의 링크는 이름만 든 알약으로 보입니다. A link inside a paragraph shows as a pill with just its name.

  • 고치기 — 알약을 클릭하거나 화살표로 들어가면 원문이 펼쳐집니다. Edit — click the pill or move into it with the arrow keys, and its source opens up.
  • 꺼내기 — 알약 끝의 ⬇ 를 누르면 문단 아래의 링크 노드가 됩니다. Pull out — click the ⬇ at the end of the pill to turn it into a link node below the paragraph.
  • 넣기 — 링크 노드를 문단 위로 끌어다 놓으면 알약이 됩니다. Tuck in — drag a link node onto a paragraph and it becomes a pill.

이미지 노드(⌥7)에 그림 주소를 넣으면 그림이 보입니다. 유튜브 주소를 넣으면 영상 표지가 뜨고, ▶ 를 누르면 창이 열려 재생됩니다. Put an image address in an image node (⌥7) to show the picture. A YouTube address shows the video poster; click ▶ to play it in a window.

복사해서 AI 에게Copy it to an AI

오른쪽 마크다운 패널의 [복사] 를 누르면 지금 보이는 범위가 마크다운으로 복사됩니다. ChatGPT · Claude · Gemini 같은 AI 의 입력칸에 그대로 붙여넣으세요. 제목과 목록이 살아 있어 AI 가 구조를 그대로 이해합니다. [Copy] in the Markdown panel on the right copies what is shown as Markdown. Paste it straight into ChatGPT, Claude, Gemini or any other AI. Headings and lists survive, so the AI sees your structure as it is.

이렇게 고르고 복사하면Select this, then Copy 복사되는 범위You get
문서 제목The document title 문서 전체The whole document
제목 하나A heading 그 장만Just that chapter
Shift+클릭으로 제목 여러 개click several headings 고른 장만 모아서Just those chapters, together

기본값 [헤딩정렬] 은 가장 얕은 제목이 # 가 되도록 맞춰 줍니다. 장 하나만 복사해도 깔끔한 문서가 됩니다. The default, [Align Headings], makes the shallowest heading a #. Even a single chapter comes out as a tidy document.

붙여넣기 — AI 의 답이나 다른 곳의 마크다운을 복사해 와서, 노드를 고른 채 ⌘V 를 누르면 지도에 가지로 붙습니다. 파일로는 [내보내기] 로 .md 를 저장하고, [가져오기] 로 .md 를 문서로 들여옵니다. Pasting — copy an AI's answer or any other Markdown, select a node and press ⌘V, and it lands on the map as branches. For files, [Export] saves an .md and [Import] brings .md files in as documents.

발표하기 (F5)Presenting (F5)

슬라이드를 따로 만들지 않습니다. F5 를 누르면 지금 문서가 그대로 슬라이드쇼가 됩니다. You don't build slides separately. Press F5 and the current document becomes a slideshow.

문서에서In the document 슬라이드로In the show
맨 앞의 Title : · Subtitle : 문단A Title : · Subtitle : paragraph at the top 제목 슬라이드Title slide
첫 제목 앞의 문단Paragraphs before the first heading 서문Preface
# 제목들headings 목차Table of contents
# 제목 하나heading 장 표지Chapter cover
## 제목 하나heading 내용 슬라이드Content slide

쇼 안에서는 → · Space 다음, ← 이전, ↑ ↓ 제목 사이, F 전체화면, Esc 끝내기입니다. 본문의 이미지와 링크는 카드가 됩니다. During the show: → · Space next, ← previous, ↑ ↓ between headings, F full screen, Esc to end. Images and links in the body become cards.

문서 지키기Keeping your documents safe

  • 자동 저장 — 쓰는 동안 저절로 저장됩니다. 문서는 이 컴퓨터 안에만 있고 서버로 보내지지 않습니다. Saving — everything is saved as you write. Documents stay on this computer and are never sent to a server.
  • 휴지통 — 지운 문서와 폴더는 휴지통으로 가고, [되돌리기] 로 꺼낼 수 있습니다. Trash — deleted documents and folders go to the Trash; [Restore] brings them back.
  • 백업 — [설정] > [일반] > [전체 백업] 으로 모든 문서를 .zip 하나로 받아 두고, 새 컴퓨터에서는 [복원] 으로 되살립니다. Backup — [Settings] > [General] > [Back Up All] saves every document into one .zip; on a new computer, [Restore] brings them back.
