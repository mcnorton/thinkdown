노드에는 세 가지 상태가 있습니다 A node has three states

한 번 클릭하면 선택, 더블클릭하면 편집 입니다. 그리고 아무것도 건드리지 않은 상태가 읽기 전용입니다. 같은 Enter 라도 선택 중일 땐 새 노드를 만들고, 편집 중일 땐 입력을 마칩니다. 편집을 마치려면 Enter 또는 Esc 를 누르면 됩니다. One click selects it, a double click edits it, and otherwise it's read-only. That's why the same Enter does two things: while selected it creates a new node, while editing it finishes your input. Enter or Esc ends editing.

선택은 Esc 로만 풀립니다. 입력을 마쳐도, 캔버스 빈 곳을 눌러도 방금 쓰던 노드는 선택된 채로 남습니다 — 다른 노드를 고르면 그쪽으로 옮겨갈 뿐입니다. 그래서 키보드로 이어서 작업할 때 "지금 어디에 있는지"를 잃어버리지 않습니다. Only Esc clears the selection. Finishing your input doesn't, and neither does clicking empty canvas — the node you just wrote stays selected until you pick another one. Keyboard work never loses track of where you are.

선택한 노드는 화면 밖으로 나가지 않습니다. 새 노드를 만들거나 링크 썸네일이 늦게 도착해 맵이 밀려나면, 그 노드가 화면 가운데로 돌아옵니다. 반대로 직접 스크롤해서 옆으로 치워 둔 노드는 그대로 둡니다 — 화면을 되돌려 놓지 않습니다. The selected node never leaves the screen. If adding a node or a late-arriving link thumbnail pushes the map around, that node comes back to the centre of the frame. A node you scrolled away from yourself is left alone — the view is not yanked back.

트리 넓히기Growing the tree

키Key 하는 일Does
Tab 지금 노드의 자식 제목을 만듭니다. 문서 제목에서 누르면 첫 챕터가 생깁니다. Creates a child heading. On the document title, that's your first chapter.
Enter (선택 상태)(selected) 같은 층에 형제 노드를 만듭니다. 제목이면 제목이, 본문이면 같은 종류의 본문이 생깁니다. Creates a sibling — a heading next to a heading, a body node of the same type next to a body node.
Shift+Enter 제목에서 누르면 그 제목에 딸린 본문 노드를 붙입니다. 깊이에 상관없이 언제든 됩니다. On a heading, attaches a body node to that heading, at any depth.
Esc 편집을 마치고 선택 상태로 돌아갑니다. Ends editing and returns to the selected state.

내용이 비어 있는 새 노드에서는 형제가 만들어지지 않습니다(노드가 살짝 흔들립니다). 빈 노드만 잔뜩 생기는 일을 막기 위한 장치입니다. A brand-new empty node won't spawn siblings (it shakes instead). It keeps you from filling the map with blanks.

본문 종류 바꾸기 — Alt+1 ~ Alt+8 Body types — Alt+1 to Alt+8

본문 노드에 포커스가 있을 때 누릅니다. Press these while a body node has focus.

키Key 종류Type 마크다운Markdown
Alt+1문단Paragraph그냥 단락plain text
Alt+2불릿Bullet* 항목item
Alt+3개요Outline1. 항목item
Alt+4인용Quote> 인용quote
Alt+5코드Code펜스로 감싼 코드 블록a fenced code block
Alt+6표TableGFM 표 (격자에서 편집)a GFM table, edited in a grid
Alt+7이미지Image![alt](url)

노드 왼쪽 위의 종류 태그를 클릭하거나 우클릭 → 종류 변경으로도 고를 수 있습니다. 다만 내용이 들어 있는 노드는 글(문단·불릿·개요· 인용·코드)끼리만 바꿀 수 있습니다 — 표·이미지·링크로 바꾸면 내용이 사라지기 때문에, 그 전환은 Alt 단축키로만 열어 두었습니다. You can also click the type tag at the node's top-left, or right-click → change type. Note that a node with content only switches among the text types (paragraph, bullet, outline, quote, code) — turning it into a table, image, or link would throw the text away, so those conversions are reserved for the Alt shortcuts.

타이핑만으로 바뀌기도 합니다. 문단에서 1. 을 치면 개요로, * 또는 - 를 치면 불릿으로, https://… 뒤에 공백을 치면 링크로 바뀝니다. Typing switches types too. In a paragraph, 1. turns it into an outline, * or - into a bullet list, and a https://… followed by a space into a link.

목록 안에서 (불릿 · 개요 · 인용) Inside a list (bullet, outline, quote)

목록은 노드 하나에 여러 줄로 씁니다. 마커와 번호는 알아서 붙습니다. A list lives in one node, several lines deep. Markers and numbers take care of themselves.

  • Enter — 같은 깊이로 다음 항목이 생깁니다. Enter — next item at the same depth.
  • Tab / Shift+Tab — 항목을 한 단계 들여쓰거나 내어씁니다(번호도 다시 매겨집니다). Tab / Shift+Tab — indent or outdent the item (numbering recalculates).
  • 항목 맨 앞에서 Backspace — 앞 항목과 합쳐집니다. 실수로 Enter 를 눌러 생긴 항목을 되돌릴 때 씁니다. 항목이 하나뿐이고 비어 있으면 마커가 사라지고 그냥 문단이 됩니다. Backspace at the start of an item — merges it into the one above. That's how you undo an Enter you didn't mean. If it's the only item and it's empty, the marker drops and it becomes a plain paragraph.

표 · 이미지 · 링크Tables, images and links

표는 더블클릭해서 편집합니다. Tab 으로 옆 칸, Enter 로 아랫줄로 갑니다(마지막 줄이면 행이 하나 늘어납니다). 편집 중에만 보이는 거터의 ＋ 로 행·열을 더하고 🗑 로 지웁니다. Tables open on a double click. Tab moves to the next cell, Enter to the row below (adding a row at the end). The gutter's ＋ adds a row or column, 🗑 removes one — both appear only while editing.

이미지 · 링크는 보이는 줄이 곧 입력란 입니다. 평소엔 읽기 전용이라 글자처럼 보이다가, 고치고 싶은 줄을 더블클릭 하면 그 자리에서 편집됩니다. Tab 으로 다음 칸, Enter 로 마칩니다. Images and links are edited on the line you see. Each line is read-only until you double-click the one you want to change, and it becomes editable right there. Tab moves to the next field, Enter finishes.

  • 새 링크에는 주소만 넣으면 됩니다. 표시 텍스트 줄은 값이 정해지기 전까지 아예 보이지 않습니다 — 주소를 넣은 뒤 이름을 따로 지어 줄 필요가 없습니다. example.com 처럼 https:// 를 빼고 써도 확정할 때 알아서 붙습니다. A new link only needs the address. The label line isn't shown at all until it has a value — not even while you're editing, so there's no second field asking to be filled in. Type example.com without the https:// and it is added for you on confirm.
  • 주소를 확정하면 가져오는 중… 이 잠깐 뜨고, 그 페이지의 제목과 대표 이미지가 한 번에 채워집니다. 제목을 못 가져오면 example.com 같은 도메인이 들어갑니다. Confirm the address and the node briefly shows 가져오는 중… before the page's title and cover image land together. If the title can't be fetched, the label falls back to the domain (example.com).
  • 채워진 뒤에 표시 텍스트 줄이 나타납니다. 마음에 들지 않으면 더블클릭해서 고치면 됩니다. 직접 쓴 표시 텍스트는 주소를 바꿔도 그대로 남습니다. 주소 줄 오른쪽의 ↗ 를 누르면 확인 후 브라우저로 열립니다. Once filled, the label line appears; double-click to reword it — and a label you wrote survives a change of address. The ↗ at the end of the address line opens it in your browser after a confirmation.
  • 가져오려면 해당 사이트에 접속해야 하므로, 원치 않으면 설정 → 일반 → 페이지 썸네일에서 끌 수 있습니다. Fetching means contacting that site, so you can turn it off under Settings → General → Page thumbnails.
  • 이미지도 쓰는 방법은 완전히 같습니다. 위에 적은 링크 이야기가 그대로 적용됩니다 — 주소만 넣으면 되고, 표시 텍스트는 자동으로 채워진 뒤에 나타나며, 더블클릭해서 고칩니다. 유튜브 주소를 넣으면 영상 포스터와 ▶ 가 뜨고 표시 텍스트가 영상 제목이 됩니다. ▶ 또는 ↗ 를 누르면 창이 열려 거기서 재생됩니다 — 맵 위에서 영상이 돌아가지 않습니다. Images behave identically — everything said above about links applies as written: the address is all you enter, the label appears once it has been filled in for you, and you double-click it to reword it. Paste a YouTube URL and you get the video's poster with a ▶ on it, labelled with the video's title. Press ▶ or ↗ and it opens in a window to play there — nothing plays inside the map itself.
  • 다만 그림은 잘리지 않습니다. 링크 썸네일은 카드 모양에 맞춰 자르지만 이미지 노드에서는 그림이 곧 내용이라 비율을 그대로 지킵니다. 같은 이유로 불러오지 못하면 알려 줍니다(링크 썸네일은 조용히 숨깁니다). The picture itself is never cropped, though. A link's thumbnail is trimmed to the card's shape, but in an image node the picture is the content, so its proportions are kept. For the same reason a picture that fails to load says so, where a link thumbnail just disappears.

구조 바꾸기 (마우스)Restructuring with the mouse

동작Gesture 결과Result
노드를 다른 노드 위에 놓기Drop a node onto another 그 노드의 아래로 이동합니다. 제목이면 깊이(#→##)가 알아서 맞춰집니다. It moves under that node. Headings re-level themselves (# → ##).
노드를 노드 사이에 놓기Drop a node between two nodes 형제 순서만 바뀝니다(계층은 그대로). Only the sibling order changes; the hierarchy stays.
선택한 제목 위·아래의 ↑ ↓↑ ↓ around a selected heading 같은 부모 안에서 앞뒤 제목과 자리를 바꿉니다(사이에 있는 문단 형제는 건너뜁니다). 딸린 하위 노드는 함께 움직입니다. Swaps the heading with the one before or after it under the same parent (paragraph siblings in between are skipped). Everything nested under it comes along.
우클릭 → 삭제Right-click → delete 노드를 지웁니다. 하위 노드가 있으면 몇 개가 함께 지워지는지 먼저 물어봅니다. Removes the node. If it has children, it tells you how many go with it first.

내용을 다 지워도 노드는 사라지지 않습니다. 지우는 방법은 우클릭 [삭제] 하나뿐이라, Backspace 를 몇 번 더 눌렀다고 가지가 통째로 날아갈 일이 없습니다. Clearing a node's text never deletes it. Right-click delete is the only way out, so no amount of Backspace will wipe out a branch by accident.

제목에 관한 세 가지 규칙Three rules about headings

  • 문단에서 친 # 는 그냥 글자입니다. 해시태그처럼 남고 제목으로 승격되지 않습니다(문단 하나 때문에 계층이 튀는 것을 막습니다). A # typed in a paragraph is just a character — it stays a tag and never promotes, so one paragraph can't jump the hierarchy.
  • 제목 앞의 # 마크는 표시 전용입니다. 글자 크기와 색이 제목과 구분되어 있고, 편집 대상이 아니라서 실수로 지워지지 않습니다. 단계(# 의 개수)는 Tab 으로 하위 제목을 만들거나 가지를 드래그해 옮길 때만 바뀝니다 — 오타 하나로 트리가 평평해지는 사고가 없습니다. The # mark in front of a heading is display only. It is set apart from the title in size and colour, and it isn't editable, so it can't be deleted by accident. The level (how many #) changes only when you add a child with Tab or drag a branch somewhere else — one stray keystroke can never flatten the tree.
  • 비어 있는 제목은 Backspace 한 번으로 문단이 됩니다(하위 노드가 없을 때). An empty heading turns into a paragraph with one Backspace (as long as it has no children).
